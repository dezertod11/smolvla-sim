# Передача управления Codex в VS Code

Это резервный вход, а не второй параллельный управляющий. Пока desktop-чат ведёт
проект, не запускать здесь второго агента. Сначала остановить его работу и
расписание, проверить активные jobs, затем продолжить в одном IDE-чате.

Начальное сообщение после передачи:

```text
/goal Выполни обязательные критерии docs/TASK.md. Сначала прочитай AGENTS.md,
docs/STATUS.md, docs/AUTONOMY.md и docs/RUN_BUDGET.md. Не считай окружение или
один успешный эпизод выполненным заданием. Проверь активные jobs и продолжи их,
не запускай дубликаты. Управляй H100/ПК-1 через scripts/control.py.
Обучение допускается только при явном ранее полученном согласии пользователя
на бюджет и наличии approved-budget.json. Самостоятельно этот файл не утверждай.
Следуй плану экспериментов, проверяй результаты, исправляй причины ошибок,
сохраняй команды, конфиги, checkpoints и доказательства. Между экспериментами
выполняй ROS2, mock-тесты и документацию. Обновляй STATUS.md после этапа.
Если лимит исчерпан или нужен недоступный доступ, изложи конкретный блокер;
не выдумывай результаты и не уменьшай критерии приёмки.
```

Goal продолжает работу в пределах доступного окружения/лимитов, но не включает
компьютер и не восстанавливает сервер после перезагрузки. Долгие процессы
запускаются через jobs.py, не остаются привязанными к терминалу чата.
Если control worker отсутствует, его запускает Open-PC1.cmd на ноутбуке или
`bash scripts/start_control.sh` в WSL ПК-1; ключи в контейнер не копировать.
