# Внутренняя история разработки

Этот файл не относится к материалам тестового задания. Здесь собраны ссылки на
служебные документы, которые использовались при разработке и эксплуатации
нескольких машин, редактора и автоматизированных инструментов. Они намеренно не
включены в README для проверяющего.

- `AGENTS.md` — внутренние правила рабочих сред и автоматизации.
- `docs/STATUS.md` — подробный хронологический журнал экспериментов.
- `docs/AUTONOMY.md` — управление длительными вычислениями.
- `docs/RUN_BUDGET.md` — внутренний бюджет запусков.
- `docs/VSCODE_HANDOFF.md` — передача управления между рабочими сессиями.
- `setup/CODEX_NETWORK.md` — внутренняя настройка сети редактора.
- `setup/CONNECTION_REPAIR_2026-10-12.md` — восстановление удалённой среды.
- `setup/RECOVERY_2026-10-06.md` — перенос Docker Desktop и восстановление WSL.
- `setup/VALIDATION.md` — исторические проверки первоначальной среды.

Скрипты удалённого запуска и синхронизации сохранены для воспроизводимости
истории экспериментов, но не требуются для проверки итогового решения по четырём
командам из README.
