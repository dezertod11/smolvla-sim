## Как работать

1. На ПК-1 запустить Docker Desktop и дождаться готовности Engine.
2. На ноутбуке открыть `setup\Open-PC1.cmd`.
3. В VS Code выбрать **Dev Containers: Reopen in Container**.
4. Работать с кодом в `/workspace`; обычная проверка: `bash scripts/check.sh`.

Launcher не меняет постоянную PowerShell Execution Policy. Docker wrapper
использует CLI Docker Desktop и проверяет движок до выполнения команд.
В основном Compose нет инструкции build, а pull запрещён. Полная сборка
возможна только отдельной командой `bash scripts/pc1.sh build`.

На заключительной проверке свободно около 53 ГБ на C: и 29 ГБ на D:.
Резервная копия занимает около 40 ГБ на D: и пока сохранена. Перед большими
загрузками или сборками нужно снова проверить место. Полный LIBERO не следует
скачивать на D: без расчёта объёма; для обучения предусмотрен H100.
